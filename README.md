# 解放小脑瓜 - 微信小程序

基于 uniapp + Vue3 开发的微信小程序，支持自定义费用、人员和分摊规则。

## 功能特性

- 📅 选择月份，自动计算月份天数
- 💰 自定义费用项，例如房租、网费、聚餐、设备租赁费，记账时填写金额
- 📆 可选天数比例分摊，自定义「周期总天数」「参与天数」的显示名称
- 👥 配置参与人员、份额、部分分摊和金额转移
- 📱 完美适配微信小程序
- 🎨 精美的 UI 设计

## 可配置分账

人员、名字和分摊比例在计算器编辑页配置，不需要改代码发版。历史账单保留当时的人员名字和金额。

新计算器默认只有一个可改名的「费用」项，不绑定水电燃气或房主场景。可以添加多项费用，并在规则中选择总费用或某一项费用；费用名称改变后，旧账仍显示当时的名字。列表、统计图表和海报均按账单实际费用项显示。

按需开启「天数比例」，字段名称可以设成「服务周期天数 / 使用天数」「活动总天数 / 参与天数」等。按天数占比会将份额乘以参与天数占比，按天数占比均摊还会除以总人数；周期可以超过一个月。开启「只取一部分」时按该比例提取费用，再用剩余费用步骤分完。

- 原李子计算器：`总费用 × 入住天数 ÷ 当月总天数 ÷ 总人数`。该人员步骤开启「只取一部分」，选择「按天数占比均摊」、份额填 1；其他人员通过「上一步剩下的总费用」按约定比例分摊。
- 原鸽子计算器：水费和燃气费四人均摊，电费按 1:1:2:2 分摊；特殊规则再转移橙子的一半费用。这些旧配置继续兼容。
- 例如总费用 300 元、3 人、房主入住半个月：房主 50 元；剩下 250 元，其他两人按 1:1 分摊则各为 125 元。
- 每条规则最终必须分完整笔费用，同一项费用和已分完的剩余费用不能重复分摊。
- 试算、账单和海报共用后端计算结果。金额按分分配，尾差优先补给小数余数较大的人，余数相同按配置顺序，确保合计等于总费用。
- 旧账迁移采用独立标记，删除账单或计算器后不会因重启重新导入；上一版本生成的房主默认 /2 规则仅自动修正一次，旧账金额不重算。

回归验证：`npm test`；后端使用 JDK 17，在 `backend` 目录执行 `mvn test`；小程序构建使用 `npm run build:mp-weixin`。

通用费用使用配置中的 `fees: [{key, name, emoji}]`、请求中的 `fees: {key: amount}`，账单保存含名称的费用快照。旧三项费用列继续保留，旧账不重算；缺少新费用快照的旧账自动按原三列读取。部署需同步更新前后端，后端现有的 Hibernate `ddl-auto: update` 会添加可空的 `bills.fees` JSON 列。持久化回归使用隔离的 H2 内存数据库。


```bash

```

```bash
# 构建微信小程序
npm run build:mp-weixin
```

## 代码架构

### 模块化设计

- **utils/config.js**: 集中管理配置信息
- **utils/helpers.js**: 通用工具函数（日期处理、金额格式化等）
- **utils/validator.js**: 表单验证逻辑
- **utils/calculator.js**: 费用计算逻辑
- **pages/index/index.vue**: 主页面，使用 Vue3 Composition API

### 可扩展性

1. **配置扩展**: 在 `utils/config.js` 中添加新配置
2. **功能扩展**: 在相应的工具文件中添加新方法
3. **页面扩展**: 在 `pages/` 目录添加新页面
4. **计算规则扩展**: 修改 `utils/calculator.js` 中的计算逻辑

## 费用计算规则

- **总费用** = 水费 + 电费 + 燃气费
- **房主应承担** = (总费用 × 房主居住天数 / 总天数) / 3
- **剩余费用** = 总费用 - 房主应承担
- **谢林珠应承担** = 剩余费用 / 2
- **张锦豪应承担** = 剩余费用 / 2

## 开发说明

### 开发工具

1. 安装 HBuilderX 或使用 VS Code + uniapp 插件
2. 安装微信开发者工具
3. 运行 `npm run dev:mp-weixin`
4. 在微信开发者工具中打开生成的 `dist/dev/mp-weixin` 目录

### 注意事项

1. 首次运行需要配置 `manifest.json` 中的微信小程序 appid
2. 小程序需要配置合法域名（开发阶段可关闭域名校验）
3. 使用 Vue3 Composition API 编写组件
4. 样式使用 rpx 单位适配不同屏幕
