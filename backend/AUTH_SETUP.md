# 微信账号、共享与历史数据绑定

前后端需要同时更新。接口默认要求登录，不再开放原共用的 cards/lizi-bills/gezi-bills 接口；旧表保留供迁移核对。开发环境也使用真实微信登录，不提供伪造账号或匿名访问的开关。

## 本机 Docker 启动

项目根目录运行 `./start-backend.sh`。启动前脚本会读取 `backend/.env` 并检查微信登录参数；没有配置时会生成该文件并提示填写，不会停止现有容器。实际 `.env` 已被 Git 忽略，文件权限为仅当前用户读写。

已准备好本项目 AppID。请在本机编辑 `backend/.env`，填入对应的 `WECHAT_APP_SECRET`；`LEGACY_OWNER_OPENID` 首次可留空。填写后再次运行 `./start-backend.sh`，脚本会重新构建并启动服务。仅执行 `docker restart` 不会加载新增环境变量。

若只需更新已在运行的后端，在 `backend` 目录执行 `docker compose up -d --no-deps --build backend`。这会重建后端容器，保留现有 MySQL 服务及数据卷。更换 AppSecret 后也需要重新创建后端容器。

非 Docker 启动时，`.env` 不会被 Spring Boot 自动读取，需要在启动 Java/Maven 的进程环境或 IDE 运行配置中设置下面的变量。

## 部署配置

在运行后端的环境（本地终端或云托管环境变量）配置：

| 变量 | 用途 |
| --- | --- |
| `WECHAT_APP_ID` | 与实际编译的小程序 AppID 一致 |
| `WECHAT_APP_SECRET` | 对应小程序的 AppSecret，仅存服务端 |
| `LEGACY_OWNER_OPENID` | “很小一颗李子”管理员账号在此小程序中的 OpenID，用于一次性绑定全部尚无归属的历史计算器 |

小程序 `src/manifest.json` 的 **mp-weixin.appid** 也必须使用同一真实 AppID，不能用游客模式测试账号隔离。后端需能请求 `https://api.weixin.qq.com/sns/jscode2session`；如微信后台启用了相关 IP 白名单，配置后端实际出口 IP。

AppSecret 不放到前端，不提交到 Git，也不需要在聊天里发送。服务端通过 `wx.login` 的临时 code 换取身份，然后签发 30 天有效的随机会话；小程序每次冷启动重新确认微信身份，不沿用上一账号的缓存；数据库只存会话和邀请的 SHA-256 摘要。账号按 OpenID 的摘要精确查找，避免数据库默认不区分大小写的排序规则混淆身份。OpenID 不从客户端传入，不信任外部传来的 X-WX-OPENID 请求头。测试仅在测试进程中替换微信上游，生产代码没有测试账号入口。

## 把现有数据归给“很小一颗李子”

1. 先配置微信登录，更新前后端。请使用“很小一颗李子”对应的微信账号打开小程序。
2. 打开首页 **我的账号 → 复制我的迁移标识**，取得该账号在当前小程序中的 OpenID。昵称不能用于绑定，改成同名也不能认领。
3. 管理员把该值设置为后端的 `LEGACY_OWNER_OPENID`，重启后端。已经登录过的账号会在启动完成后绑定；尚未登录的账号在首次登录时绑定。
4. 该账号回首页刷新，应能看到原来的计算器和账单。核对后可移除这个迁移环境变量。绑定幂等，只处理 `owner_id IS NULL` 的记录，不会抢走任何已有归属的计算器。历史账单金额、费用与人员快照保持不变。

未绑定的历史数据保持不可见，不会分配给第一个登录的人。**不要只按昵称猜 OpenID，也不要上线匿名回退逻辑。** 此代码修改不会替你操作线上数据库或配置实际 AppSecret。

Hibernate 当前 `ddl-auto: update` 会为 `calculators` 新增可空 `owner_id`，为 `bills` 新增可空 `created_by`，并创建 `app_accounts`、`login_sessions`、`calculator_companions`、`calculator_invitations` 四张表。生产发布前照常备份数据；若使用数据库变更审批流程，应先按实体字段完成建表/加列，再发布应用。

## 同伴与分账人员

- 创建者能修改规则、背景，邀请/移除同伴，删除账单及无账单的计算器。
- 同伴能查看计算器、历史及新账单，试算并新增账单，不能修改配置、邀请其他人或删除账单。
- 分账人员表示金额分给谁；同伴表示谁有权限使用。这两个列表互相独立：邀请和移除不会改变分摊配置或旧账。
- 创建者在计算器正文区打开 **同伴 → 生成一份新邀请 → 发送微信邀请**。每份邀请仅供一名新同伴使用，有效期 7 天；对方打开后需确认加入。
- 邀请可以撤销。移除同伴立即撤销后续接口访问权限，同时撤销该计算器全部旧邀请，避免对方凭旧邀请重新进入；可以再生成邀请重新加入。已经收到的数据无法从对方设备撤回。
- 微信分享卡片需要在真实小程序环境验证。开发者工具或模拟器不能代替两个真实微信账号的分享验收。
